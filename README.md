# 菲娜 · 黑翼召唤器

这是供创世回廊、酒馆助手及 MVU 使用的装备模块。脚本会把黑翼召唤器发放给存档主角「菲娜」，装备在主手，并在变量更新时同步等级、品质、属性和武器面板。

仓库不是游戏本体。仅上传文件不会使原游戏自动加载此模块，需要在酒馆助手脚本库导入并启用一次。

## 使用

1. 将人物预设中的角色名称设为「菲娜」，正常开始游戏，让 MVU 初始化人物变量。
2. 下载 `blackwing-remote.json`，在**酒馆助手 → 脚本库**中导入并启用。此文件从本仓库通过 jsDelivr 加载装备代码。
3. 停用此前的「黑翼召唤器修复」旧脚本，避免两套成长规则同时改写装备。游戏原有辅助计算脚本继续启用。
4. 自动发放后查看主手装备；也可点击「发放并修复黑翼召唤器」。原主手武器转存装备箱，不删除。

网络或 CDN 不可用时，可改为导入 `blackwing-local.json`。它包含相同完整代码，无需从仓库加载。远程版、本地版二选一。更新脚本后重新载入游戏页面；CDN 的 main 分支缓存可能延迟更新，正式使用可在导入文件的 URL 中将 `@main` 改为已经发布的提交 SHA。

## 装备行为

- 固定绑定菲娜；写入 `stat_data.人物.装备列表`，类型为「武器」、部位为「主手」、`装备箱: false`。
- 不需要变身；实际拥有的有效卡片插入后，按装备效果规定的动作、使用次数与品质预算调用能力。
- 读卡过程带机械音播报的叙事规则。契约兽技能卡会让契约兽临时现身，执行一次技能后消失，不提供独立回合、常驻单位或重复攻击。
- 不发放基础卡、生存卡、契约兽、职业技能或技能树；成长直接更新武器，不写入人物特质。
- 旧版装备会改为本版的基础品质与预算。已有强化、品级、冷却和使用记录保留，升级不恢复使用次数。

## 品质与预算

自动成长采用用户提供的**基础品质**，专属身份不提供额外升阶。没有掷掉落检定，也不把等级上限当成默认品质。

| 菲娜等级 | 自动品质 | 等级品质上限 | 词条数 |
| --- | --- | --- | --- |
| 1—18 | 普通 | 稀有 | 1 |
| 19—34 | 精良 | 卓越 | 1 |
| 35—49 | 稀有 | 卓越 | 2 |
| 50—74 | 稀有 | 传说 | 2 |
| 75—89 | 卓越 | 史诗 | 2 |
| 90—99 | 传说 | 神话 | 3 |
| 100 | 史诗 | 神话 | 3 |

因此，100 级自动得到史诗，**不会自动成为神话**。代码保留神话效果预算供今后扩展，但本版不会自动发放神话品质。

词条按品质逐步出现：

1. `[翼召读卡]`：每战一次，消耗一次攻击次数；卡片本身也消耗一次。只能读取实际持有且可用的卡片，只选择其一项能力。伤害使用该品质的基础倍率和等级成长，召唤伤害、治疗及护盾再乘 60%。次数、范围、倍率按卡片与武器限制中更严格者处理。
2. `[翼幕回护]`：稀有开始获得，每战一次消耗反应，合拢护手抵挡一次命中伤害。护盾比例按品质为 10% / 15% / 25% / 40% / 60%，伤害结算完毕后剩余护盾消散。
3. `[暗翼循迹]`：传说开始获得，仅在非战斗探索中追踪已读卡片对应契约兽足迹，感知检定 +2，同类取最高。

普通、精良没有敌方豁免或治疗护盾预算，因此只承载单体伤害及无数值增益的非战斗交互。稀有及以上可按词条限定读取范围伤害、治疗、护盾及单一状态卡；控制至多一轮，必须进行相应属性豁免，成功无效果。范围伤害最多为 5 尺半径，敏捷豁免成功减半。免死、额外回合、长期免疫等不由本装备承载，不能借高品质卡片绕过武器预算。

技能加成写在装备的 `属性加成` 中（例如「基础」「全技能」），不会创建技能树或赠送技能；「基础」属性键与「基础卡组」无关。

## 实际执行范围

脚本实际执行装备发放、存档写入、等级品质同步、属性预算及主手面板更新；它在原辅助计算和装备守卫之后执行，修复新武器被默认转入装备箱的问题。

读卡音、技能演出和战斗结算写在装备的 `效果` 中，供游戏叙事及规则结算读取。本模块没有音频文件或音频播放器，也没有通过按钮直接扣次数、掷骰、扣血或操纵召唤物；实际使用卡片时，应由游戏同步相应使用记录。升级及重载不清除这些记录。

## 开发与验证

运行 `node --test blackwing.test.cjs`，不需要安装依赖。测试覆盖 1—100 级的品质上限、属性和词条预算，旧存档修复，重复发放，角色隔离，冷却保留，以及 MVU 装备守卫后的正确落位。

代码在 `blackwing-summoner.js`；规则依据在 `equipment-rules.md`；1 级装备示例在 `blackwing-level-1.json`。如果修改代码，请用 `node package.cjs` 重新生成导入 JSON，再运行测试。
